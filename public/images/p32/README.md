# public/images/p32

Client-approved photography sourced from the shared Google Drive folder
(`https://drive.google.com/drive/folders/1uSgU3vd8xpMSiZcC1mOlOLgdC1kR-jlA`),
downloaded locally, renamed semantically, and lightly treated (partial
desaturation toward the system's black-and-white ground, contrast bump,
resized, saved as quality-82 JPEG) to match the rest of the site's visual
language. Originals are not committed; only the treated, renamed working
files live here.

All 11 images in the folder were inspected before selecting. Selection
favors real photography and genuine editorial framing over anything that
reads as staged stock-photo posing, per the client's visual direction.

## Processing notes

Each image is: converted to RGB, resized so its longer edge is at most
1200-1800px (matched to its placement), blended with a grayscale copy at a
per-image ratio (0.35-0.75, lighter touch on the canine photography,
heavier on tactical/night imagery) to bring it into the site's
black-and-white system without going fully monochrome, given a small
contrast lift, and saved as quality-82 JPEG. No content is invented,
cropped to remove context in a misleading way, or captioned with claims
beyond what the image itself shows.
